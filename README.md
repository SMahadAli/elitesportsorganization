# Elite Sports Organization (ESO)

Welcome to the official website repository of **Elite Sports Organization (ESO)**.

ESO is a sports organization focused on organizing local sports tournaments, leagues, and sporting events while building a strong sports community.

## 🏆 About ESO

**Elite Sports Organization (ESO)** organizes competitive and engaging sporting events across different sports.

Our goal is to:

* 🏟️ Organize professional-quality local tournaments
* 🏆 Provide opportunities for athletes to compete
* 🤝 Build a strong local sports community
* 📢 Promote sports and sporting talent
* ⚡ Create exciting and memorable sporting events

## 🌐 Website

This repository contains the source files for the ESO official website.

The website is deployed using **Netlify** and connected to **GitHub**, allowing website updates to be managed through the repository.

## ✏️ Updating the Website

Website content can be updated directly through the GitHub repository.

Common updates include:

* Changing text
* Replacing images
* Updating event information
* Adding new sports
* Updating contact information
* Adding new sections

After changes are pushed to GitHub, **Netlify automatically deploys the updated website**.

## 🚀 Deployment

The website is hosted on **Netlify** and connected to this GitHub repository.

### Deployment process

```text
Make changes
     ↓
Commit changes to GitHub
     ↓
GitHub updates repository
     ↓
Netlify detects changes
     ↓
Website automatically updates
```
